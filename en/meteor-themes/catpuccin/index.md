# Catpuccin Addon (Theme) for Meteor Client

## Introduction

The Catpuccin Addon is a theme designed for Meteor Client, a popular mod for Minecraft. This addon transforms the user interface with its visually appealing features, including rounded corners, a variety of color schemes inspired by the [Catpuccin Palette](https://catppuccin.com/palette/), smooth animations, and dynamic font support. It aims to provide an "epic" look and feel, enhancing the overall Minecraft experience. Whether you’re tweaking your game’s aesthetics or seeking a more modern interface, this addon offers a fresh take on Meteor Client’s visuals.

## Key Features and Modules

The Catpuccin Addon enhances Meteor Client with several distinctive features, making it a compelling choice for players who value aesthetics and customization. Below are the key features:

### Rounded Corners

The addon introduces rounded corners to the Meteor Client interface, giving it a modern, sleek appearance. While described as “kinda wonky” by the author, this feature adds a unique visual flair. The author has noted potential improvements in future updates, suggesting ongoing development to refine this aspect.

### Accent Colors

The theme incorporates all accent colors from the [Catpuccin Palette](https://catppuccin.com/palette/), offering a variety of flavors such as Latte, Frappé, Macchiato, and Mocha. These color schemes provide a consistent and visually appealing aesthetic, allowing users to personalize their interface to match their preferences.

### Animations

The addon includes configurable animations with adjustable durations and types, such as Linear, Ease In, and Ease Out. These animations enhance the user experience by making transitions smoother and more engaging, adding a polished feel to the interface.

### Font Rendering

Dynamic font rendering is a standout feature, supporting regular, bold, and italic fonts. For the best visual experience, the author recommends setting the font to Arial or a similar sans-serif font in the “Config” tab. This flexibility ensures that text displays clearly and stylishly across different UI elements.

While the repository mentions plans for custom HUD elements like a Module Array, these are not yet implemented and are considered future enhancements.

## How to Enable the Theme

Enabling the Catpuccin theme is straightforward and can be done in a few simple steps:

1. **Download the Latest Release:** Click the [link](#useful-links) above to download the latest version of the addon compatible with your Minecraft version.
2. **Place in Mods Folder:** Extract the downloaded file and place it in your `.minecraft/mods` folder, where Meteor Client is installed.
3. **Select the Theme:** Open Meteor Client, navigate to the ClickGUI, go to the “GUI” tab, and select “Catpuccin” from the theme dropdown menu.
4. **Configure Font (Optional):** For the best visual experience, go to the “Config” tab and set the font to Arial or a similar sans-serif font.

These steps ensure the theme is applied correctly, transforming the Meteor Client interface with the Catpuccin aesthetic.
