## Introduction

Meteor Additions is a collection of addons designed to enhance the Meteor client, a widely-used Fabric-based client for Minecraft. Drawing inspiration from Wurst7, it introduces a variety of features and modules that provide players with greater control and customization, enriching the Minecraft gameplay experience. These addons are tailored to work seamlessly with the Meteor client, offering tools for server management, creative gameplay, automation, and communication.

## Key Features and Modules

MeteorAdditions offers a range of modules and features to enhance various aspects of Minecraft gameplay. Below is a detailed look at each:

### ModMenu Integration

- **Functionality**: Enables players to open the Meteor ClickGUI directly from the ModMenu, a standard feature in Fabric mods.
- **Benefit**: Simplifies access to Meteor’s settings and configuration options, eliminating the need to navigate complex menus.

### Servers Option

- **Functionality**: Enhances the multiplayer menu with server discovery, cleanup tools, and easy saving/loading of server lists.
- **Benefit**: Streamlines the process of finding, organizing, and connecting to multiplayer servers, improving the multiplayer experience.

### Spawn Items Module

- **Functionality**: Allows players to create item entities in creative mode.
- **Benefit**: Ideal for testing item behaviors or spawning specific items for creative building projects, offering flexibility in creative gameplay.

### Creative Tab with OP Items

- **Functionality**: Adds a new tab in the creative inventory containing overpowered (OP) or custom items. Players can add items using the `.save-item` command or by editing the `additions_items.txt` file in the `.minecraft/meteor-client/` directory.
- **Benefit**: Provides easy access to powerful or custom items, enhancing both creative and survival gameplay.

### AutoSpectre

- **Functionality**: Automates actions related to the Spectre item, based on a pull request from the Meteor client repository ([MeteorDevelopment/meteor-client/pull/1932](https://github.com/MeteorDevelopment/meteor-client/pull/1932)).
- **Benefit**: Saves time by automating repetitive tasks, making gameplay more efficient.

### Translator Module

- **Functionality**: Configures the included google-chat mod to translate chat messages in real-time.
- **Benefit**: Facilitates communication in multiplayer environments by translating messages into the player’s preferred language, breaking down language barriers.
