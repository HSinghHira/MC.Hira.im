## Introduction

HKUtils is a Minecraft mod designed to work seamlessly with Meteor Client, enhancing the gameplay experience with a variety of utility features and commands. Tailored specifically for Minecraft version 1.21.4, it offers players tools to customize and streamline their gameplay. Developed by H1ggsK, the mod is actively maintained, with its latest update released on July 4, 2025, ensuring compatibility with the latest Minecraft version. Whether you're looking to tweak gameplay mechanics or automate certain tasks, HKUtils provides a range of practical and creative features.

## Supported Minecraft Versions

HKUtils is designed to work with the following Minecraft version:

- **Minecraft 1.21.4**

::: tip
For players using older Minecraft versions, the mod can be used with [ViaFabricPlus](https://modrinth.com/mod/viafabricplus), which enables compatibility with earlier versions.
:::

## Key Features and Modules

HKUtils includes a variety of modules and commands that enhance gameplay. Below is a table summarizing the key features based on information from from the official GitHub repository:

| Module Name     | Description                                                                          |
| --------------- | ------------------------------------------------------------------------------------ |
| Weather Changer | Spoofs client-side weather, enabling flight with a Riptide trident in clear weather. |
| MaceDMG         | A direct port of `MaceDMG` from Wurst, allowing maximum damage with a mace.          |
| AutoShear+      | An enhanced version of `Auto Shearer` with sheep color picking functionality.        |
| FPS Limiter     | Limits the frames per second (FPS) for the client, optimizing performance.           |
| ForwardChat     | Forwards in-game chat to a Discord Webhook for external communication.               |
| AutoTotemLegit  | Automatically moves a totem to the offhand when the inventory is opened.             |
| Commands        | Includes `.ping`, `.lifeadvice`, and `.troll1` for various gameplay tweaks.          |

These features cater to players who want to enhance their Minecraft experience, from automating tasks to adding playful or strategic elements. Note that some features, like ForwardChat, may be restricted on certain servers due to their potential for abuse.

## Usage Considerations

While HKUtils offers exciting features, some modules may not work on servers with anti-cheat protections. For example, ForwardChat could be restricted due to its ability to send chat data externally. Always check server rules before using mods to avoid bans. The mod’s commands, like `.troll1`, are designed for fun but should be used responsibly to maintain a positive gaming environment.
